Building This Portfolio

Role: UI/UX Designer & Front-End Developer

Timeline: September 2026 - Present

Rather than relying on a website builder or template, I designed and developed this portfolio from scratch. It serves as a live demonstration of my technical proficiency in front-end development and my psychological approach to information architecture, actively bridging my studies in Computer Science and Cognitive Science.

DESIGN & ARCHITECTURE

Modular CSS Architecture

I built the site from scratch using HTML and CSS, managing the code through Git and hosting it on GitHub Pages. To ensure a flawless experience on both desktop and mobile, I designed a flexible, reusable layout system.

By relying on a globally standardized .split-layout structure and strict CSS variables for color management, the site adapts smoothly to any screen size without needing bulky third-party templates or external code libraries."

Designing for the Brain

Every aesthetic decision was filtered through a UX and cognitive psychology lens. I specifically chose a high-contrast dark green and beige color palette to reduce screen glare and eye strain compared to a stark white background.

By aggressively utilizing negative space, standardizing vertical margins, and keeping paragraphs concise, the layout naturally guides the user's eye down the page. This structural rhythm prevents information fatigue and minimizes cognitive load for people scanning the site.
